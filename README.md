# student_expense_system
A Python-based dashboard that manages student records and expense tracking using lists, dictionaries, loops, and conditional statements.
Student Expense Dashboard

Overview

Student Expense Dashboard is a Python project that combines student record management and expense tracking in a single application.

The project collects student details, calculates marks statistics, and tracks expenses with expense analysis.

Features

Student Management

- Add student names
- Enter marks for each student
- Calculate total marks
- Calculate average marks
- Display Pass/Fail status

Expense Tracking

- Add expense names
- Enter expense amounts
- Calculate total expenses
- Find highest expense
- Find lowest expense

Concepts Used

- Python Lists
- Dictionaries
- For Loops
- Nested Loops
- Conditional Statements
- User Input
- Basic Data Analysis

Sample Output

Student Report

- Student Name
- Marks
- Total
- Average
- Result

Expense Report

- Expense Name
- Expense Amount
- Total Expense
- Highest Expense
- Lowest Expense

Technologies Used

- Python 3
